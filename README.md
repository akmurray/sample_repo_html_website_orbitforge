# Sample Repo Orbitforge

Orbitforge is a **test website repo** intended for pipeline and agent workflow exercises.

## What this repo includes
- Multi-page static site under `public/`
- Shared CSS + JS utilities + page-specific scripts
- Local static server script (`scripts/serve.js`)
- Deterministic fixture data for known outcomes (`public/assets/data/products.json`)
- A small summary verification workflow (`data/tasks.json` + scripts)

## Run locally
- `npm run serve`
- Open `http://localhost:4173`

## Why this exists
Use this repo as a realistic target for:
- cloning and branch workflows
- content and UI edits across multiple files
- agent-driven implementation tasks
- deterministic validation of expected output changes
